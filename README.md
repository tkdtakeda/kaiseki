# kaiseki (folderscan)

フォルダを読み取り専用で走査し、構成・内容・データ構造・ファイル間の連携を 1 つのレポートにまとめるツールです。

## 使い方
- `folderscan.bat` をダブルクリック（またはフォルダをドロップ）
- 初回とソース変更後は、Windows 標準の C# コンパイラで `src\` をビルドしてから実行します
- 結果はデスクトップの `folderscan\` に出力されます
- 旧版レポートとの比較は `compare_reports.bat`

## 設定
値は次の順に重ねて読み込まれ、後のものが優先されます。

1. プログラムの既定値（v5.18 と同じ値）
2. `settings.ini`（ツールに同梱される初期値。更新で上書きされることがあります）
3. **この PC の設定** `%LOCALAPPDATA%\folderscan\user_settings.json`

自分用に変えたい値は、入力欄で `s` を押して設定メニューから変更してください。変えた項目だけが PC 側に保存されるので、ツールを更新して `settings.ini` が上書きされても残ります。

| 設定メニューでの入力 | 動作 |
|---|---|
| 番号 / キー名 | 説明・settings.ini の値・現在の値を表示して、新しい値を入力 |
| `KEY=値` | その場で変更（例 `DIAGTOP=20`） |
| 値の入力で `-` | その項目をこの PC から消し、settings.ini の値に戻す |
| `r` | この PC の値をすべて消す |
| `l` / Enter | 一覧を再表示 / 入力欄に戻る |

- 一覧の `*` がこの PC の値です。変更はすぐ保存され、次のスキャンから使われます。
- 不正な値（例 0/1 の項目に 2）は保存されません。
- 使った設定はコンソールの起動時とレポート冒頭の `Settings :` 行に出ます。
- json が壊れていた場合は `user_settings.json.bad` に退避し、settings.ini の値で動きます。

## フォルダ構成
| 場所 | 役割 |
|---|---|
| `src/App` | 起動・入力・表示・設定メニュー |
| `src/Core` | 走査の土台（設定の読み込み・PC 設定の保存、ファイル収集、レポート出力） |
| `src/Analysis` | 内容解析・依存関係の検出 |
| `src/Sections` | レポートの各セクション |
| `src/Diag` / `src/Gaps` | 自己診断・ギャップ調査 |
| `src/Map` / `templates` | 見取り図 (map.html) |
| `legacy` | 旧版 v5.18 の bat（比較用） |

## ファイルを追加・差し替えるときのルール
`folderscan.bat` は `src\` 以下の **すべての .cs** をまとめてビルドします。
- 差し替えは、元のファイルと **同じ場所・同じ名前で上書き** してください。`src\` 直下など別の場所に置くと、同じクラスが 2 つになりビルドが止まります。
- 新しいファイルは役割に合うフォルダ（上の表）に置いてください。
- `src\` には `.cs` 以外（`*_v6.1.cs.txt` などの控え）も置かないでください。控えはリポジトリの外か `legacy` へ。

変更履歴は `README.txt` を参照してください。
